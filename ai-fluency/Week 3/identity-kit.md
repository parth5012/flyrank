## 1. Palette

Built on a deep, distraction-free terminal dark theme with high-contrast cyan accents to evoke precision engineering and measurement instruments.

| Role | Color | Hex Code | Purpose |
|---|---|---|---|
| **Background Dark** | Deep Obsidian Navy | `#0a1628` | Main page canvas and root contrast |
| **Surface Dark** | Midnight Navy | `#0f1f35` | Navigation bar, header backdrop, subtle cards |
| **Surface Card** | Deep Slate | `#111d2e` | Primary case cards, break rows, code blocks |
| **Primary Accent** | Electric Cyan | `#38dafa` | CTAs, active indicators, borders, hero accents |
| **Primary Dark** | Deep Cyan | `#1ab8d8` | Hover states, pressed states, borders |
| **Success / Valid** | Terminal Emerald | `#34d399` | Status pulse, live badges, success feedback |
| **Warning / Fix-Now** | Amber Signal | `#fbbf24` | `[fix-now]` tags, open limitation alerts |
| **Muted Text** | Cool Slate | `#94a3b8` / `#cbd5e1` | Long-form body copy, high-readability text |

## 2. Typography

Two font families, selected for readability, technical precision, and zero-weight contrast:

1. **Display & Headings: `Space Grotesk`** (sans-serif)
   - Geometric, clean, modern, slightly wide letterforms that look intentional on large headings.
   - Weights: `400` (body copy fallback), `600` (subheads), `700` (hero titles).
2. **Technical Details & Labels: `JetBrains Mono`** (monospace)
   - Used for all code blocks, metadata eyebrow tags (`// SECTION 01`), stats, status indicators, and button text.
   - Weights: `400` (regular code), `500` (bold tags).
